The World Ledger: a one-page broadsheet summing up Friday 20 November 2026 — Trump's delayed Iran decision and the Senate's 51–48 war vote, the strikes on Kyiv's bridges, Kenya's Ebola all-clear, the Shenzhen nuclear pledge and the first Pacific seabed-mining lease. A Python compositor (compose_frontpage.py) sets the page in type around three press photographs and writes entry.png; main.py verifies the PNG chunk by chunk and ships it.
